🧠 Alibaba just banned Claude Code internally — and it says a lot about where the AI war is really heading.

Anthropic's Claude Code has been classified as "high-risk" software by Alibaba, with employees reportedly blocked from using it on internal systems. This isn't a performance complaint. It's a security call — and a loud one.

The concerns are almost certainly rooted in data privacy and IP exposure. When your engineers pipe proprietary code through a foreign AI tool, you're trusting that tool with your infrastructure's most sensitive logic. For a company like Alibaba, that's a non-starter.

But zoom out and the bigger story emerges. The US-China AI divide isn't just about which country builds the most powerful models anymore. It's now filtering down into the everyday tools engineers use to write code. The split is going enterprise-level — and that changes everything.
