💡 Amazon's AWS chief is going on offense — because the backlash over data center secrecy is getting too loud to ignore.

AWS CEO Matt Garman stepped into the spotlight this week to address a growing crisis of trust. Communities across the country are waking up to find massive data centers being built next door — sucking up power, water, and local resources — with little to no warning. Garman's big claim: Amazon has dropped the NDAs it once used to keep host communities in the dark.

That's a meaningful concession. But it's also a sign of how badly the PR situation has deteriorated. Local governments are furious. Environmental groups are circling. And the AI infrastructure boom is moving so fast that "we'll explain later" is no longer a viable answer.

This matters beyond Amazon. How AWS navigates this fight will set the playbook — or the cautionary tale — for every hyperscaler facing the same heat.
