💡 Anthropic's VS Code extension was backdoored for 12 hours — and nobody can fully explain how it happened.

Attackers compromised Anthropic's verified Cursor publisher account and slipped a backdoor into its VS Code extension. It sat there, live, in developers' environments for nearly half a day before anyone caught it. That's not a near-miss. That's a breach.

What makes this worse: Anthropic still hasn't clarified how the attackers got into a verified publisher account in the first place. That gap in the disclosure is its own problem. Developers deserve to know exactly what failed so they can assess their own exposure.

Developer tools are the crown jewel of supply chain attacks. A backdoored AI coding assistant touching thousands of dev environments isn't a minor hiccup — it's a reminder that the tools we trust the most are exactly the ones attackers go after.
