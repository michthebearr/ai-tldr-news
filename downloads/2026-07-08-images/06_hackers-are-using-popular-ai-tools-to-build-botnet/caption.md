🔐 Hackers figured out how to turn your AI coding assistant into a botnet-building tool — and you'd never know it.

Researchers discovered that nine of the most popular AI tools can be exploited through a technique called "HalluSquatting." Here's how it works: LLMs hallucinate package names that don't exist, recommend them to developers with full confidence, and attackers register those fake packages loaded with malicious code. The moment a developer runs the install command, they're compromised.

This isn't some theoretical edge case or elaborate jailbreak. It's a scalable attack that exploits the one thing LLMs do constantly and automatically — make stuff up and sound certain about it. The more developers lean on AI to write and ship code faster, the wider this attack surface gets.

The trust we've placed in these tools is the vulnerability.
