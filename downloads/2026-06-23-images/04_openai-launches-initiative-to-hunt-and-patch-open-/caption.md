🔐 OpenAI is now hunting security bugs in open source software — and patching them for free.

The company just launched a new initiative that uses its own AI models to scan open source projects for vulnerabilities and help fix them. It's defensive security work, offered as a contribution to the broader ecosystem — no charge, no strings attached.

Which is a genuinely smart move. The entire AI industry — including OpenAI itself — is built on open source infrastructure. Keeping that foundation secure isn't charity, it's self-interest with good PR attached.

The details are still thin. Which projects are in scope, how deep the scanning goes, and what the patch pipeline looks like haven't been fully spelled out yet. But the framing is clear: OpenAI wants to be seen as a steward of the ecosystem, not just a company extracting value from it.

Goodwill engineering. And it just might work.
