💡 Hugging Face is quietly hosting AI models built to generate nonconsensual sexual deepfakes — and barely lifting a finger to stop it.

A new report from European nonprofit AI Forensics found that the platform is riddled with models explicitly designed to create explicit, nonconsensual images of women and children. They're not buried. They're easy to find and easy to run.

Hugging Face calls itself the GitHub of AI — the open, democratic hub where anyone can share and build models. But GitHub has content policies with actual consequences. Right now, Hugging Face's enforcement looks like a sign-on-the-door that nobody checks.

This is the real stress test for the open AI ecosystem. Either it self-regulates before governments decide to do it for them — or regulators use stories like this to justify cracking down on everything, including the tools that actually matter.
