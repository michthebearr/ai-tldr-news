## Alibaba Calls Claude Code "High-Risk" and Bans It Internally

Alibaba has reportedly classified Anthropic's Claude Code as high-risk software and banned employees from using it. The move signals that Chinese tech giants are drawing hard lines around which foreign AI coding tools can touch internal infrastructure — almost certainly driven by data security and IP concerns.

**Why it matters:** When one of the world's largest tech companies blacklists a leading AI coding assistant, it underscores how the US-China AI split is now playing out at the enterprise tool level, not just the model level.

**Source:** [TechCrunch](https://techcrunch.com/2026/07/04/alibaba-reportedly-bans-employees-from-using-claude-code/)

## Fanfiction Communities Are Tearing Themselves Apart Over AI Detection

A grassroots movement has swept through fanfic platforms like AO3, with writers trying to hunt down and expose authors using generative AI. The problem: the detection methods being deployed are unreliable, meaning innocent writers are getting caught in the crossfire and accused of cheating.

**Why it matters:** This is a preview of what happens when communities try to self-police AI use without any reliable tools to do so — the witch hunt becomes as damaging as the problem it's trying to solve.

**Source:** [The Verge](https://www.theverge.com/tech/960854/ai-fanfiction-ao3-claude-detector)
